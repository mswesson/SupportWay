# AI Support Front — панель оператора техподдержки

Фронтенд (React + Vite) для оператора техподдержки. Работает поверх бэкенда
[AISupprot](../AISupprot) (FastAPI): REST для действий, WebSocket для обмена сообщениями.

## Запуск локально

**Требования:** Node.js, запущенный бэкенд AISupprot на `http://localhost:8080`.

1. Установить зависимости:
   `npm install`
2. (опционально) Переопределить адрес бэкенда: создайте `.env` с `VITE_API_BASE="http://localhost:8080"`.
3. Запустить:
   `npm run dev`

## Авторизация

Оператор логинится по ФИО и паролю (эндпоинт `POST /api/v1/auth/login`).
Первого оператора нужно создать на бэкенде через `POST /api/v1/users`
(см. README бэкенда).
