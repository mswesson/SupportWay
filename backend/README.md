# 💬 Сервис агрегации чатов техподдержки

> Принимает обращения клиентов, распределяет их между операторами и связывает стороны в реальном времени.

## 🎯 Зачем
Когда у клиента возникает вопрос, его обращение нужно быстро отдать наименее загруженному
свободному оператору и дать сторонам общаться вживую. Сервис берёт на себя очередь,
распределение, переключение операторов и доставку сообщений.

## ⚙️ Как это работает
```text
Внешнее приложение ──REST──▶ [Сервис: очередь + распределение] ──WebSocket──▶ Оператор
        (бот/сайт)  ◀──WebSocket── (обмен сообщениями в реальном времени) ──▶
```
Внешнее приложение создаёт обращение через REST — сервис сразу находит и резервирует
оператора. Дальше обе стороны обмениваются сообщениями по WebSocket, а сервис ведёт
переписку и синхронно сообщает о статусе сессии.

## ℹ️ Что НЕ делает
- не реализует сами каналы (телеграм, виджет сайта) — это внешние приложения;
- не хранит и не отправляет файлы/медиа — только текстовые сообщения;
- не содержит фронтенд оператора — только бэкенд (REST + WebSocket).
